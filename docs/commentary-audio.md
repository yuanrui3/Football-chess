# Match commentary audio

The game includes original football-chess commentary scripts, generated on 16 October 2026 with Runway’s stock British voice **Tom** using its expressive speech model. These are AI-generated calls; no Derek Rae, Stewart Robson or other named commentator voice has been cloned or included.

The generated MP3 files are bundled under `dist/audio/commentary/`; the script and event mapping are in `dist/commentary-clips.js` and `dist/commentary.js`. Playback is local to the website and sends no match data to an audio service. Runway credentials and private asset URLs are not included.

Runway’s published [commercial-use guidance](https://help.runwayml.com/hc/en-us/articles/21668707517587-Can-I-use-the-content-I-made-in-Runway-for-commercial-purposes) permits use of generated content without its own noncommercial restriction, subject to the [terms](https://runway.com/terms-ofuse) and [usage policy](https://runway.com/safety/usage-policy). This bank was generated through the user’s authenticated Runway workspace. It does not contain voice models, stock preview recordings, or access to the speech-generation service. Keep this provenance with redistributed project copies.

`commentary-audio-provenance.json` records each original script, generation task ID, file size, duration and SHA-256 hash. It contains no authentication tokens or private download URLs.

The default **Instant analysis · Hugo + Tom** mode uses prepared whole-sentence Hugo recordings for observed tactical sequences, formation, individual contributions and spatial details, with Tom’s recorded shots and goals. Hugo’s library is generated locally from the existing bundled model and stock voice, without a speech service; scripts, hashes, generation settings and audio checks are in `hugo-commentary-library-provenance.json`. The reproducible generator is `scripts/build-hugo-commentary-library.mjs`. Library playback has no model download or runtime speech-generation delay. Clips are requested as needed and may be cached by the browser.

**Live Hugo · slower** remains an optional local synthesis mode. Recorded-only and device voices are also available. Hugo modes retain captions if audio fails; recorded-only mode can fall back to a device voice. Generic calls serve both teams; names, precise scores and assists remain in the match display. Captions match the recording actually selected; a separate context label names the assessed team and piece. Past-tense spatial and tactical recordings can finish across ordinary actions after a valid playback start. Each shot result is revealed only with the visible outcome. The three-second pace restriction and immediate user-stop controls apply throughout. Automatic shot/result calls wait for an already-started Hugo sentence, with a single latest relevant reaction retained; automatic replay/full time preserve it. Team-named stat calls use exact shot counts and explicitly approximate possession percentages.
