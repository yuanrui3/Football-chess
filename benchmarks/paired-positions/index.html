When Should a Language Model Change Its Move? Paired Shot and Pass Decisions in Purdue Football Chess

Yuanrui Chen

The Purdue Football Chess paired-position benchmark tests whether a language model changes its action when a defender moves one square. Each model sees one board at a time and chooses from three actions. The rules engine evaluates every option. In half of each task’s pairs the edit changes the best action. In the other half the same action remains best.

Two decisions, 100 pairs

Shooting · 60 pairs, 120 boards
Choose a declared target or disguise the shot. The goalkeeper responds to minimize the chance of a goal. The release includes coordinates and rules, prompts adding legal goalkeeper replies, and prompts adding the scoring odds for each reply.
Passing · 40 pairs, 80 boards
Choose a teammate for a pass that will reach its receiver. The attack holds its next move. The best pass maximizes the probability of retaining the ball after the defender’s next challenge.

What the paired scores show

Solving a pair requires picking the engine’s best action on both boards. On shots from coordinates and rules, Gemini 3.1 Flash-Lite solved 12 of 60 pairs and a geometric shot-line rule solved 52. On passes, Gemini and a rule based on tackle shapes and ranges each solved 38 of 40 pairs. The scores describe one recorded response per input on deliberately selected positions. Full-match play and the models’ training histories fall outside these measurements.

Reproduce the results

From benchmarks/paired-positions/ in a checkout of revision 8e87600, run the following with Node.js 24.2 or later. The scorers use the included files and run offline.

node anc/score.mjs
node anc/pass/reproduce.mjs
node anc/native/verify.mjs

Inspect the shot scorer, geometry baseline, pass scorer and engine verification script.
